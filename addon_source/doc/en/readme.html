RSS Feed & Category Finder for NVDA

Most modern websites, blogs, and news portals still support RSS and Atom feeds, but they rarely show a visible RSS button anymore. Feed links are often hidden inside HTML source code or scattered across dozens of topic pages. For screen reader users, navigating cluttered, ad-heavy news sites just to check the latest headlines or find a working feed URL can be slow and frustrating.

RSS Feed & Category Finder solves this problem. Enter any website address, and it automatically discovers both the primary RSS/Atom feed and sub-category feeds (such as Sports, Technology, Health, Business, or Entertainment) in seconds—allowing you to copy feed URLs, bookmark your favorite feeds, or read the latest articles right inside NVDA without opening a web browser.

Why Use This Add-on?

  • No More Digging Through Page Source: Simply type a website address (for example, bbc.com/news, onlinekhabar.com, or setopati.com) and press Enter.
  • Finds Category Feeds Automatically: Scans site navigation to uncover topic-specific feeds and groups them neatly by category.
  • Read Articles Without Clutter: Load any discovered or saved feed to read headlines, dates, and clean article summaries directly in NVDA.
  • Works With International Sites: Handles Unicode URLs, compressed feeds, and varied SSL configurations reliably.
  • Batch JSON Scanner: Scan a JSON list of websites in parallel and export categorized RSS feed reports.

Keyboard Shortcuts

  • NVDA + Control + Shift + F: Open the RSS Feed & Category Finder dialog (also available under NVDA Menu → Tools → RSS Feed & Category Finder...).
  • Alt + C: Copy the selected feed URL to the clipboard.
  • Alt + A: Copy all feed URLs in the current category.
  • Alt + S: Save the selected feed to Favorites.
  • Alt + D: Remove the selected feed from Favorites.
  • Alt + R or Enter on a feed: Load recent articles for the selected feed.
  • Alt + O: Open the selected article in your default web browser.
  • Alt + U: Copy the selected article link.
  • Alt + B: Batch-check a JSON file of websites and export categorized feeds.
  • Alt + H: Open this help guide.
  • Escape: Close the dialog.
